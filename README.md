# skilog.cz

Web aplikace SkiLog, hostovaný na GitHub Pages s doménou `skilog.cz` (soubor `CNAME`).

Teď je zveřejněná jen stránka „Spouštíme brzy“ (`index.html`, `styles.css`).
Plný prezentační web je rozpracovaný ve složce `draft/`, která je v `.gitignore` a na GitHub nejde.
Až bude schválený, přesune se obsah `draft/` do kořene.

Náhled: otevřít `index.html` v prohlížeči.
